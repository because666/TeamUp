# Documentation Instructions

本文件适用于 `docs/` 下的所有修改，并补充根目录 `AGENTS.md`。

- 文档必须使用简体中文；代码标识符、命令、字段名和标准术语保留英文。
- 每份规范在标题下标注 `Status`、`Owner` 和 `Last Updated`。
- 只使用 `Confirmed`、`Proposed`、`TBD`、`Deprecated` 四种状态。
- 已确认事实必须能追溯到 Accepted ADR、双方共识或已实现并验证的行为。
- 提案必须写明需要谁确认，不得用肯定语气伪装成既定方案。
- 接口、数据字段、需求和验收条件使用稳定 ID，避免仅靠标题引用。
- 修改行为规范时，检查并更新索引、相关交叉链接、任务文件与 `CURRENT.md`。
- 不在多个文件复制同一份长规则；指定一个权威文档，其他文件链接过去。
- 不删除历史决策。废弃时改为 `Deprecated`，说明原因并链接替代方案。
- 状态文件记录结果和证据，不记录冗长思考过程或聊天原文。
- 所有相对链接在提交前必须检查有效性。

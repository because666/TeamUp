# TeamUp 发布清单

> Status: Proposed<br>
> Owner: 角色 A（产品）/ 角色 B（技术）<br>
> Last Updated: 2026-08-10

每次 staging 或 production 发布复制本清单到对应发布任务中填写，不能直接勾改本模板。

## 1. 发布信息

- [ ] 发布版本、提交 SHA、负责人和时间窗口已记录
- [ ] 变更摘要、影响用户和关联任务/PR 已记录
- [ ] 是否包含 API、迁移、配置、AI 提示或隐私变化已说明
- [ ] 回滚负责人和停止发布条件已确认

## 2. 代码与验证

- [ ] 目标提交已经评审并合入预期分支
- [ ] 自动化测试、lint、类型检查和构建通过
- [ ] 契约与实现一致，客户端兼容性已验证
- [ ] 数据迁移在 staging 和备份副本验证
- [ ] 登录、资料、项目、匹配、沟通、邀请主路径烟测通过
- [ ] 权限、拉黑、举报和注销关键路径验证
- [ ] AI 关闭、超时和限流降级验证

## 3. 安全与配置

- [ ] 没有密钥、测试账号或调试开关进入构建产物
- [ ] 生产密钥通过安全配置注入并遵循最小权限
- [ ] CORS/域名、微信配置、数据库和对象存储指向正确环境
- [ ] 日志脱敏、限流、审计和告警启用
- [ ] 隐私政策/服务条款版本与产品行为一致

## 4. 数据与运维

- [ ] 发布前备份完成且恢复步骤可用
- [ ] 迁移预计耗时、锁表风险和回滚/前滚策略已评估
- [ ] 健康检查、关键指标和错误率基线已记录
- [ ] 容量、连接池、外部 API 限额和 AI 预算已检查
- [ ] 重大故障联系人和沟通渠道可用

## 5. 发布后

- [ ] 版本和迁移状态正确
- [ ] 健康检查与核心接口正常
- [ ] 真实环境最小烟测完成且未污染生产数据
- [ ] 错误率、延迟、登录失败、发布失败和邀请失败无异常
- [ ] 已记录发布结果、已知问题和观察窗口
- [ ] `CURRENT.md` 与任务状态更新

## 6. 回滚触发条件

出现以下任一情况应暂停或回滚，除非负责人确认有更安全的前滚方案：

- 登录或主链路大面积失败；
- 权限绕过、隐私泄漏或密钥暴露；
- 数据丢失、重复成员、迁移不可逆异常；
- 错误率显著上升且原因不明；
- 无法关闭异常 AI/外部服务调用导致持续影响或费用失控。
